# 视频接口与时钟契约

以下只记录从当前工程或官方资料能直接定位的事实。比赛指南 C1 第 18 页建议自备显示器支持 `1280×720@60Hz`；这不是已实现的视频配置。若系统目标采用此有效区，则有效像素吞吐的设计下限为 `1280×720×60 = 55,296,000 pixel/s`；它不等于包含消隐的像素时钟，也不能代替接口带宽和时序分析。来源 ID 见 [`05-source-ledger.md`](05-source-ledger.md)。

已确认的**器件能力**：A1 产品表列出 PH1P35MDG324 有 2 个 MIPI D-PHY；S1 产品宣传规格列出 SC500CS 支持 10/8-bit 2-Lane MIPI。实际模组接线、CSI-2 输出格式、RAW 位宽、Bayer 顺序和 Lane 速率仍未知；不能将产品能力填成下表的工程配置。

## 每段额外核对

- 帧首、行首、帧尾、行尾发生在哪一拍？消隐区是否进入算法？
- 像素和坐标如何对应？HSYNC、VSYNC、DE 与 valid 是否同周期？
- 一拍几个像素？行长度、帧长度和有无丢拍如何定义？
- FIFO、DDR 或 CDC 位于何处？跨域数据采用什么协议？
- 模式和阈值从哪个时钟域来？何时锁存，是否保证整帧一致？
- 算法插入点前是否已经完成 RAW/Bayer 到灰度或 RGB 的转换？
