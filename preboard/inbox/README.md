# 官方资料收件目录

把从 [`06-package-manifest.md`](../06-package-manifest.md) 所列分享页取得的**原始文件**放在本目录，先不要解压或覆盖同名文件。优先顺序：

1. `lab_ex1_mipi_hdmi_SC500_720P.zip`
2. `新HX1P35A开发板手册-HDL版2604.pdf`
3. `SC500CS_数据手册_V1.8.pdf` 与 `SC500CS.pdf`
4. `DS1300_PH1P_Datasheet.pdf`、`UG1316_安路科技PH1P系列FPGA MIPI用户手册.pdf`
5. 安装前阅读 `【重要提醒・开发环境版本统一】.txt`；TD 安装包按本机空间和版本需求取得，不必与工程源码混放。

收到后先在 `../06-package-manifest.md` 填写日期、字节数、SHA-256、压缩包清单，再于独立目录解压审计。`HX1P35B` 的管脚资料不得直接用于题目指定的 `HX1P35A`。
