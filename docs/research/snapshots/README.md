# 原始资料快照

这里保存需要离线留存的原始资料副本或副本说明。

## 规则

- 比赛 PDF 快照位于 `competition/topic2.pdf`。
- 新增原始资料时，记录原文件名、公开来源 URL 和获取日期；不提交本机绝对路径。
- 网页资料优先保存来源 URL、访问日期和整理后的资料卡；只有网页内容会影响复现时才保存 Markdown 快照。
- GitHub 工程优先记录仓库 URL、commit/ref 和许可证；不把未筛选的大型仓库批量复制进主工程。
- 原始快照只读保存，分析结论写入 `anlogic/`、`camera/`、`mipi-video/` 或 `algorithms/` 的资料卡。
