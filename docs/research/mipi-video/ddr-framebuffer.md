# DDR 和帧缓存资料卡

- 关联 Goal：1、2、4、8
- 类型：系统架构
- 状态：需要结合安路官方 IP 手册验证

## 作用

DDR 帧缓存用于解耦摄像头输入和 HDMI 输出，并在需要时保存一帧或多帧图像。它还可以吸收不同视频时钟域之间的速率差异。

## 需要核对

- 输入写时钟和输出读时钟。
- 像素格式和每像素位宽。
- 行地址、帧地址和 burst 长度。
- 单缓冲、双缓冲或环形缓冲。
- 空闲、满、帧完成和撕裂保护信号。
