# PH1P35 平台资料卡

- 平台：安路 PH1P35
- 比赛开发板：HX1P35A
- 比赛器件：PH1P35MDG324
- 来源：[比赛题目 PDF](../competition/topic2-requirements.md)
- 状态：已确认赛题平台，具体工程细节待补

## 与项目的关联

PH1P35 是题目二的目标 FPGA。后续所有 RTL、时钟、IP、管脚约束和资源分析，都必须以当前 PH1P35 工程和安路工具输出为准。

## 当前已知资源

赛题资料给出的平台资源包括 LUT、DFF、分布式 RAM、ERAM、MIPI、DSP、PLL、MCU 和 HDMI 等资源。具体资源占用和时序结果要以 TD 当前工程报告为准。

## 尚未确认

- 当前开发板的完整管脚约束文件。
- PH1P35 对应 MIPI D-PHY/CSI-2 IP 的版本和配置方法。
- PH1P35 对应 HDMI 输出例程的工程路径。
- 题目二配套 SC500CS 初始化表的准确版本。

## 使用规则

PH1A 资料只能作为架构参考；不得直接照搬 PH1A 的 PLL、DDR、MIPI PHY、HDMI PHY 和约束文件。
