# 题目二资料库

本目录服务于安路 PH1P35 题目二：基于 SC500CS 摄像头完成 MIPI 输入、实时图像处理、HDMI 输出和 OSD 展示。

使用入口是 [INDEX.md](INDEX.md)。开始任何题目二相关工作前，先读取入口索引，再读取当前 Goal 对应的阅读清单。

资料优先级：

1. 当前 PH1P35 工程和安路官方资料
2. 比赛题目 PDF
3. 安路其他系列的摄像头和视频参考设计
4. 通用协议、算法教程
5. 其他 FPGA 平台的 GitHub 工程

其他 FPGA 工程默认只用于学习架构、算法和验证方法。未经验证，不得直接复制其中的 MIPI PHY、PLL、DDR、HDMI 和管脚约束。
